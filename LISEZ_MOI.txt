PWA iPhone autonome après installation. iOS exige un premier chargement via HTTPS pour installer le service worker. Publier ces fichiers sur un hébergement statique HTTPS, ouvrir index.html dans Safari, puis Partager > Sur l'écran d'accueil > Ouvrir comme app web. Aucun serveur Python ni base distante n'est nécessaire. Les factures sont analysées dans le navigateur et l'historique reste local.
